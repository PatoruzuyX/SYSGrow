## **5. Recommended minimum containment contracts**

The following is my proposed refinement. These are planning requirements, not accepted architecture or implementation authorization.

| Checkpoint | Minimum mandatory exit contract                                                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| D0         | Accepted design decisions, named contract owners, dependency interfaces, explicit deferred capabilities and validation requirements.                                           |
| R1a        | Exclusive runtime authority, construction-only non-owner mode, deny-by-default command admission and inhibited recovery where evidence is unavailable.                         |
| R1b        | Qualified minimum transaction and claim mechanism, current approval and authorization checks, cancellation and expiry handling, or strict inhibition of unsupported execution. |
| R2a        | Complete command-origin inventory, mandatory final dispatch boundary, qualified authorization, typed outcomes and minimum durable recovery.                                    |
| R2b        | Synthetic multiprocess ownership, stale-owner exclusion, restart fencing and explicitly bounded recovery qualification.                                                        |
| R3a        | Full transactional workflows, shared-resource reservations, topology, freshness, calibration and durable quarantine.                                                           |
| R3b        | Lifecycle coordination, independent protection requirements, shutdown reconciliation and deployment-profile evidence.                                                          |
| Q          | Integrated fault qualification, applicable device-specific evidence and individual finding dispositions.                                                                       |

The key architectural distinction is:

- **Contract definition:** establishes what an implementation must guarantee.
- **Minimum containment:** enforces a restricted subset of those guarantees or denies the affected operation.
- **Full qualification:** proves the complete applicable contract with the required evidence.

These cannot be treated as interchangeable milestones.
